# Checkpoints

The RAQEEB-CCTV checkpoint is not duplicated in this repository. `src/model_loader.py` downloads the version-pinned checkpoint to the Hugging Face cache and verifies SHA-256 `9788ae90e35715b1012bbe1bd1b56daa636cb3a1429b0b90ba4b8148a1ff0bcf` before loading.
