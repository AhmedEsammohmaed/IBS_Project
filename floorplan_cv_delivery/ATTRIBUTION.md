# Third-party model and data attribution

The optional pretrained weight used by this package is **RAQEEB-CCTV v1.0.0**, published by the RAQEEB-CCTV contributors at [Hugging Face](https://huggingface.co/swedishtech/RAQEEB-CCTV). Model card and weights are licensed **CC BY-NC 4.0**. Attribution and non-commercial restrictions apply; obtain written separate permission for commercial use. The binary is downloaded at runtime and is not redistributed in this repository.

The model card reports training data merged from 16 public sources, including CubiCasa5K and FloorPlanCAD; data licenses may impose additional restrictions on weight use. Consult the upstream model card, source datasets, and the applicable license texts before deployment.

The original CubiCasa5K source is [CubiCasa/CubiCasa5k](https://github.com/CubiCasa/CubiCasa5k), paper: Kalervo et al., “CubiCasa5K: A Dataset and an Improved Multi-Task Model for Floorplan Image Analysis,” SCIA 2019. The upstream RAQEEB-CCTV checkpoint itself reports its dataset and attribution; this package does not redistribute the datasets.
